# Рычажный параллельный гриппер RARS01

Новый гриппер установлен и описан в `config/default.yaml`. RARS SDK и седьмой
мотор не меняются.

Логика управления уже совпадает с исходным проектом reBot:

```text
открытие по позиции → закрытие по моменту → обнаружение остановки → удержание
```

Используемые размеры:

- радиус центрального рычага — 37.5 мм;
- длина каждой короткой тяги — 40 мм;
- ширина каретки — 30 мм;
- полезное раскрытие — 100 мм;
- полезная глубина — 80 мм.

Ширина преобразуется в относительный угол мотора нелинейно:

```text
x = (w + 30 мм) / 2
theta = acos((x² + r² - L²) / (2*x*r))
motor = theta(0 мм) - theta(w)
```

Расчётный ход от 0 до 100 мм равен 0.945832 рад и находится внутри текущего
лимита `angle_open: 1.0`. Реальная проверка выполняется скриптом
`scripts/check_gripper_linkage.py`; порядок запуска приведён в Jetson README.

Калибровка `camera → End_link` остаётся действительной, если камера и сам
`End_link` физически не перемещались.
