# Замена гриппера RARS01 на механику reBot

Планируется оставить без изменений RARS01, контроллер, RARS SDK и седьмой
мотор, заменив только механическую конструкцию текущего гриппера на
параллельный гриппер reBot.

Логика управления уже совпадает с исходным проектом reBot:

```text
открытие по позиции → закрытие по моменту → обнаружение остановки → удержание
```

После установки нового гриппера необходимо измерить и вынести в отдельный
профиль конфигурации:

- направление положительного вращения мотора;
- угол полностью закрытого и полностью открытого положения;
- максимальную физическую ширину между внутренними поверхностями губок;
- момент закрытия и момент удержания;
- преобразование от центра между губками к `End_link`;
- ориентацию плоскости губок (для reBot ожидается `XY`, у текущего RARS01 —
  `XZ`);
- координаты крайних точек губок для проверки высоты над столом.

Предполагаемый выбор профиля:

```yaml
robot:
  gripper:
    active_profile: rars01_current  # позднее заменить на rebot_parallel
```

Нельзя заранее копировать исходное значение reBot `angle_open: 5.0`: предел
седьмого мотора в текущем RARS SDK равен `0…1.4 rad`, а URDF текущей механики
задаёт `0…1.0 rad`. Сначала нужно измерить требуемый ход новой конструкции.
Если он превышает 1.4 rad, отдельно меняется только предел мотора гриппера;
ограничения шести суставов руки не затрагиваются.

Калибровка `camera → End_link` остаётся действительной, если камера и
`End_link` физически не перемещались. Повторно измеряется только преобразование
`grasp center → End_link` нового гриппера.
